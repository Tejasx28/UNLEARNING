How to interpret the values. Lower target-answer overlap can support a forgetting assessment, while higher overlap on unrelated answers supports preservation on the sampled questions. Read the generated answers as well: low overlap can also reflect incorrect or malformed output.

This report shows saved measurements and examples. Opening it starts no inference or training. It covers one base model with three trained adapters. It does not establish complete deletion or preservation of all model knowledge.

Model and data
Qwen/Qwen2.5-1.5B-Instruct with the same TOFU target adapter. Forget01 contains 40 QA entries for two fictional authors. Retain generation uses 40 sampled Retain99 examples.
Shared training settings
Seed 42, five epochs, batch size 4, learning rate 5e-5 and 50 recorded optimizer updates. Each method has its own objective settings.
Generation evaluation
Forget answers, paraphrased forget answers and retain answers use a 96-token generation cap. Training and evaluation times cover different stages.
Available response evidence
Each source exports one example response and reference for each displayed category. The exports do not include exact prompt strings or every evaluated response.

Protocol source: verified comparison evidence JSON. Each adapter section links its original evaluation and training provenance.
